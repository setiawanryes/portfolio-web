SI-TANDUR

Integrated Agricultural Information System

SI-TANDUR is an Integrated Agricultural Information System developed specifically for East Lampung to help local farmers plan, monitor, and manage the planting process more efficiently.

It provides crop planning, real-time monitoring, and data-based recommendations. I developed this project as part of the 2025 East Lampung Regional Innovation Competition.

Designed for Web & Mobile, it integrates agricultural data, market prices, weather info, and a promotional hub for MITRA & MSMEs.
