Workload Analyst

Task Management System (TMS) & WLA Implementation

I conducted a Workload Analyst project using the Task Management System (TMS) and Workload Analyst (WLA) approaches. The objective was to evaluate workload balance, time efficiency, and task distribution to enhance productivity.

The first project was at PT Great Giant Food (GGF) (4 months), focusing on Admin positions. I utilized direct observation and daily activity mapping to identify workload imbalances and task duplication.

The second project was at K3DK (Accounting Sub-Dept) (2 months). I analyzed accounting processes from data entry to reporting, mapping task frequencies, duration, and complexity using TMS.

Using WLA, I compared actual workload vs ideal capacity. The results led to recommendations for task prioritization, balanced time allocation, and process optimization.

This project provides insights for GGF and KDK to build a productive, data-driven environment, supporting workforce planning and organizational improvement.
